# Xio-Shark · account defaults

This repository holds account-wide defaults for the [Xio-Shark](https://github.com/Xio-Shark) account: community health files and shared links that apply to repositories which do not define their own.

Xio-Shark is a personal account, not an organization, so this repository does **not** provide the profile page. The profile README lives in [Xio-Shark/Xio-Shark](https://github.com/Xio-Shark/Xio-Shark).

## Projects

| Project | What it is |
| :--- | :--- |
| [xiocode](https://github.com/Xio-Shark/xiocode) | Local-first terminal coding agent: turn-by-turn rollback, crash-resilient sessions, direct provider endpoints, zero telemetry. |
| [xioflow](https://github.com/Xio-Shark/xioflow) | Embeddable supervised execution kernel for AI agent runtimes: intent before spawn, confirmed stop, per-stream evidence, honest recovery. |
